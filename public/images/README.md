# Images

Drop your assets here, then update the paths in `src/lib/constants.ts`.

| Folder          | What goes here                                  | Referenced as              |
| --------------- | ----------------------------------------------- | -------------------------- |
| `logo/`         | Weshort logo (PNG/SVG, transparent background)  | `/images/logo/<file>`      |
| `backgrounds/`  | Auth page hero background (movie-poster collage)| `/images/backgrounds/<file>` |
| `icons/`        | Any misc icons (google, apple, etc.)            | `/images/icons/<file>`     |

Files in `public/` are served from the site root, e.g. `public/images/logo/logo.png` → `/images/logo/logo.png`.
